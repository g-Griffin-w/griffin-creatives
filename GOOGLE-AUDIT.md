# Free Google Business Profile audit — checklist and what to send

Use this for the free audit we offer on calls and in replies. About 15 minutes per outfitter. Everything here comes from what they show publicly, so don't guess at facts you can't see.
Related: [GBP-CLIENT-SOP.md](GBP-CLIENT-SOP.md) (what we'd do once they're a client).

## Steps
1. Search the business name plus the town on Google, signed out. Screenshot what a hunter sees.
2. Fill in the scorecard below.
3. Pick the **top 3 fixes** that would help most. Write each as one plain sentence.
4. Send the short email below. Offer a 15-minute call to walk through it.

## Scorecard (answer yes / no / not sure)
| # | Question | Result |
|---|---|---|
| 1 | Is there a Google Business Profile at all? | |
| 2 | Is it claimed (no "Own this business?" link)? | |
| 3 | Is the name exactly the business name, with no keywords added? | |
| 4 | Is the primary category right (Hunting guide or Outfitter)? | |
| 5 | Is there a service area, and does it match where they guide? | |
| 6 | Phone number and website present and correct? | |
| 7 | Are there 10+ real photos (camp, hunts, animals, guides)? | |
| 8 | Is there a description that says what they hunt, where and when? | |
| 9 | How many reviews, and is the newest one from this year? | |
| 10 | Do they reply to reviews? | |
| 11 | Is there a duplicate listing (old name, old phone)? | |
| 12 | Has anything been posted in the last 90 days? | |

## The 5 questions a hunter answers in 20 seconds
Is this a real operation? Where do they hunt? What does a hunt cost or include? Are there recent happy clients? How do I book?
Use these to explain each fix.

## Rules
- Only use what's visible on their public profile and website.
- Never ask for their Google password. They own the profile; we're only ever added as a Manager, later, if they become a client.
- Don't name a real outfitter in public posts or in content. Teardowns in content use mock examples.
- Log each audit: who, date, top 3 fixes, whether they replied.
